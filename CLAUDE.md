# CLAUDE.md — Инструкции для Cline / Claude

Этот файл содержит правила и требования, которым Cline обязан следовать при внесении изменений в проект **dayly-bot**.

## Обязанности при каждом изменении кода

1. **Проверка соответствия документации.** Перед внесением любых изменений проверьте, не противоречат ли они существующей документации в `README.md` и `CLAUDE.md`.

2. **Актуализация README.md.** Если ваши изменения затрагивают:
   - структуру проекта (новые файлы/папки, удаление, переименование);
   - логику работы приложения (новые команды, изменение поведения, новые маршруты сервера);
   - переменные окружения (новые/удалённые/переименованные `ENV`);
   - зависимости (`package.json`);
   - команды запуска/скрипты;
   - архитектуру модулей;

   — обязательно обновите соответствующие разделы `README.md`. Если описания функционала ещё нет в README — добавьте его.

3. **Добавление новых фич в документацию.** Любая новая функциональность (команда, модуль, маршрут, интеграция) должна быть задокументирована в `README.md` и/или `CLAUDE.md` в рамках того же изменения.

4. **Запись в CHANGELOG.md.** Каждое изменение, которое влияет на работу приложения (фичи, багфиксы, рефакторинг, изменения конфигурации, зависимости, документация), должно быть зафиксировано в `CHANGELOG.md`:
   - добавьте новую запись **в начало** списка;
   - формат: `## ГГГГ-ММ-ДД — <краткое описание>`;
   - описание должно быть **на английском языке**;
   - не более **200 символов** на запись;
   - одну строку на изменение.

5. **Синхронизация с реальным кодом.** Документация должна всегда соответствовать фактическому состоянию кода. Если код изменился — документация обязана быть обновлена в том же PR/изменении.

## Структура документации

| Файл          | Назначение                                                                 |
|---------------|----------------------------------------------------------------------------|
| `README.md`   | Полное описание приложения: структура, принцип работы, команды, ENV, запуск, модули. Ведётся **на русском языке**. |
| `CLAUDE.md`   | Правила и требования для Cline при работе с проектом. Ведётся **на русском языке**. |
| `CHANGELOG.md`| История изменений проекта. Ведётся **на английском языке**.                 |

## Правила ведения CHANGELOG.md

- Язык: **английский**.
- Формат даты: `ГГГГ-ММ-ДД`.
- Формат записи: `## ГГГГ-ММ-ДД — <описание>`.
- Максимум **200 символов** на одну запись.
- Каждая запись — **одна строка**.
- Новые записи добавляются **в начало** файла.
- Записывать все значимые изменения: новые фичи, исправления, рефакторинг, обновления зависимостей, изменения конфигурации.

## Напоминание

Всегда проверяйте актуальность следующих файлов после внесения изменений:

- `README.md` — описание приложения;
- `CLAUDE.md` — правила для Cline;
- `CHANGELOG.md` — история изменений.
